# Соглашение об уровне обслуживания (SLA)
## Cloud Key Management Service (Cloud KMS) и Cloud HSM

**Дата публикации:** 05 сентября 2026 г.  
**Поставщик услуги:** Google LLC  
**Документ основан на:** публичных условиях Google Cloud

---

## 1. Определения

- **Cloud KMS** — облачная служба управления криптографическими ключами.
- **Cloud HSM** — аппаратный модуль безопасности (Hardware Security Module), интегрированный с Cloud KMS.
- **Monthly Uptime Percentage** — процент доступности сервиса в течение календарного месяца.
- **Downtime (Простой)** — периоды, когда доступность сервиса падает ниже порога, определённого ниже.

---

## 2. Обязательства по доступности

Google обязуется обеспечивать следующие уровни доступности в течение каждого календарного месяца:

| Сервис | Месячный уровень доступности |
| :--- | :--- |
| **Cloud KMS API** | ≥ 99.99% |
| **Cloud HSM** | ≥ 99.99% |

---

## 3. Что считается простоем (Downtime)

Простоем считается любой период, когда:
- Cloud KMS API не отвечает на запросы более **5 минут** подряд.
- Cloud HSM не может выполнить криптографические операции более **5 минут** подряд.
- Ошибка превышает порог, определённый в технической документации.

---

## 4. Исключения

SLA **не применяется** в следующих случаях:
- Плановые технические работы, о которых Google уведомил заранее.
- Сбои, вызванные факторами вне разумного контроля Google (форс-мажор).
- Неправильное использование сервиса Клиентом.
- Сбои из-за программного обеспечения, оборудования или сетей Клиента или третьих лиц.
- Использование функций, помеченных как Alpha, Beta или Experimental.
- Квоты Клиента исчерпаны.

---

## 5. Компенсации (Service Credits)

Если Monthly Uptime Percentage опускается ниже гарантированного уровня, Клиент имеет право на кредит на будущие счета Google Cloud:

| Месячный уровень доступности | Процент кредита от стоимости сервиса |
| :--- | :--- |
| < 99.99%, но ≥ 99.0% | **10%** |
| < 99.0%, но ≥ 95.0% | **25%** |
| < 95.0%, но ≥ 90.0% | **50%** |
| < 90.0% | **100%** |

### Условия получения кредита:
1. Клиент должен подать запрос на кредит через Google Cloud Support.
2. Запрос должен быть подан **не позднее 2 месяцев** после окончания месяца, в котором произошёл инцидент.
3. Кредит не может превышать сумму, уплаченную Клиентом за соответствующий сервис в данном месяце.
4. Кредиты **не конвертируются в денежные средства** и не переносятся на другие сервисы.

## 6. Мониторинг и отчётность

Google предоставляет:
- Страницу статуса: [status.cloud.google.com](https://status.cloud.google.com)
- Метрики доступности через Cloud Monitoring
- Логи аудита через Cloud Audit Logs

---

## 7. Изменения в SLA

Google может изменять условия SLA, уведомив Клиентов не менее чем за **30 дней** до вступления изменений в силу.
